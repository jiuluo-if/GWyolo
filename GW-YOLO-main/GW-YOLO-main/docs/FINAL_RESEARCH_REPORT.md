# GW-YOLO Attention Residual 项目研究报告

## 摘要

本研究评估 Attention Residual 是否能改善引力波时频图 chirp 分割，并研究其与
YOLO26m baseline 的互补价值。固定验证结果不支持用当前 P3/P4 C2PSA 单模型替换
baseline：chirp mask mAP50-95 从 0.44584 降至 0.41077，推理成本也增加。另一方面，
两个模型的事件级错误具有互补性。通过只在验证集上校准的非对称阈值级联，GW5 事件
召回达到 100/104，同时验证集 TP/FP/FN/TN 保持 68/3/1/11。研究表明，当前
Attention Residual 的主要价值是选择性补充，而不是单模型性能替换。

## 1. 研究问题

1. P3/P4 Attention Residual 是否提高 chirp 分割质量？
2. 注意力模型是否能补回 baseline 的事件级遗漏？
3. 如何限制模型融合带来的误报代理和推理成本？
4. 在固定数据和当前负样本条件下，优化上限在哪里？

## 2. 模型

baseline 为 `runs/segment/train/weights/best.pt`。Attention Residual 为
`runs/segment/segment_new/chirp_c2psa-2/weights/best.pt`，在高分辨率 P3 和中分辨率
P4 路径加入 C2PSA。残差连接保留局部特征，自注意力用于连接被噪声分隔的弯曲轨迹。

P3 在 640 输入下约为 80×80，自注意力成本随空间位置数平方增长，因此当前结构限制
P3 深度，并把更多上下文建模放在 P4。

## 3. 数据与审计

- 训练/验证：331/83 张图像。
- 验证 chirp 阳性/阴性代理：69/14 张图像。
- GW5：429 张 H1/L1/V1 探测器时频图。
- 事件目录：161 个事件，其中 57 个质量字段不完整，排除后为 104 个。
- 事件召回：任一 H1/L1/V1 图像检出 class 0 chirp 即召回。

GW5 没有纯负事件，因此它只能评估正事件覆盖率。验证集中的 14 张无 chirp 标注图像
用于临时 FP 代理，但样本过少，不能替代 false alarms/day。

## 4. 方法

### 4.1 固定验证复核

两个现成权重在相同 83 张验证图、`imgsz=640` 和同一 Ultralytics 环境下复核
box/mask 指标、逐类指标和推理速度。

### 4.2 决策级融合

多尺度推理使用 512/640/768 输入并取每图最高 chirp 置信度。模型后融合对 baseline
与 Attention Residual 取 OR，用于检验错误互补。

### 4.3 阴性代理与按需级联

固定验证集中无 class 0 标注的图像作为阴性代理。baseline 先处理全部图像；只有
baseline 未过工作阈值时才运行 Attention Residual，从而避免完整双模型冗余。

### 4.4 非对称阈值校准

两个模型的置信度分布不同，不再强制共用阈值。在验证集上联合扫描两阈值，要求
FP<=3，最大化 TP，再选择最低可行阈值。GW5 不参与阈值选择。

## 5. 主要结果

### 5.1 单模型结构假设

| 指标 | baseline | Attention Residual |
| --- | ---: | ---: |
| 总体 mask mAP50-95 | 0.42994 | 0.39123 |
| chirp mask Recall | 0.80769 | 0.74359 |
| chirp mask mAP50-95 | 0.44584 | 0.41077 |
| 单图推理 | 27.29 ms | 46.44 ms |

当前证据否定“现有 Attention Residual 单模型优于 baseline”的假设。由于两次训练的
超参数不完全相同且只有单种子，不能把全部差异严格归因于结构。

### 5.2 错误互补

在共阈值 0.25 下，baseline@640 为 85/104，Attention Residual@640 为 88/104，
二者 OR 融合达到 99/104。全模型多尺度融合达到 100/104，但成本为 112.23 秒。

这说明平均分割质量较低的注意力模型仍可能识别 baseline 遗漏的少数形态。

### 5.3 误报代理

共阈值 0.25 时，baseline 的验证 TP/FP/FN/TN 为 67/3/2/11，完整融合为
68/5/1/9。融合多召回一张阳性图，同时增加两张阴性误报。baseline@0.20 达到
68/3/1/11，因此简单 OR 不能作为默认策略。

### 5.4 计算优化

共阈值级联在 GW5 保持 99/104，并把 FP32 耗时从 36.42 秒降至 29.55 秒。FP16
batch1 进一步降至 22.40 秒并保持事件召回。路径列表 batch2 导致系统性置信度塌缩，
因此被拒绝。

### 5.5 非对称 Attention Residual 级联

验证集选择出 baseline=0.14、Attention Residual=0.36：

| 指标 | 结果 |
| --- | ---: |
| 验证 TP/FP/FN/TN | 68/3/1/11 |
| 验证 Precision / Recall | 95.77% / 98.55% |
| GW5 召回 | **100/104（96.15%）** |
| 图像命中 | 171/429 |
| 第二模型调用 | 273/429 |
| FP32 级联耗时 | 27.21 秒 |

相对 baseline@0.20，该策略在当前验证 FP 代理不变的情况下多召回 10 个 GW5 事件。

## 6. 解释

验证图像指标与 GW5 事件召回衡量不同问题。验证 mAP 衡量实例和像素级平均质量；
GW5 只要求一个事件的任一探测器图像至少命中一次。Attention Residual 即使整体分割
质量较低，也可能对某些弯曲、微弱或噪声纹理下的轨迹更敏感。

非对称阈值把两个模型的分数分布分开处理：baseline 在较低但仍满足 FP 约束的阈值
负责主召回，Attention Residual 使用更高阈值补充低置信度区域。按需调用同时消除
已经由 baseline 判阳时的冗余注意力计算。

## 7. 瓶颈与有效性威胁

- 只有 14 张验证阴性图，每个 FP 使 FPR 跳变 7.14 个百分点。
- GW5 不含纯负观测时间，不能报告生产 Precision 或 false alarms/day。
- 现有两个模型的训练变量未完全锁定，且都只有一个随机种子。
- `GW240922_142106` 缺少输入图像，当前数据下理论召回上限最多为 103/104。
- 另外三个遗漏事件的两模型最高分均低于 0.04，继续降阈值会先破坏 FP 约束。
- 非对称阈值是验证集校准结果，仍需更大负集确认稳定性。

## 8. 研究结论

1. 当前 Attention Residual 不能作为更优单模型发布。
2. Attention Residual 与 baseline 存在可利用的事件级互补。
3. 非对称阈值级联是本轮最有效的研究策略：验证 FP 代理不变，GW5 达到 100/104。
4. 当前瓶颈已经从阈值与调度转移到数据完整性、纯负样本规模和多种子结构消融。

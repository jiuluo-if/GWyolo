# GW-YOLO 项目记忆

> 最后更新：2026-07-24。本文件记录项目结构、当前训练方案和维护约束；后续修改训练或推理流程前应先阅读本文件。

## 1. 项目目标

本项目使用 Ultralytics YOLO 分割模型处理引力波时频图像，识别两类目标：

| 类别 ID | 名称 | 说明 |
| --- | --- | --- |
| 0 | `chirp` | 引力波 chirp 时频轨迹，通常细长、弯曲、连续或局部微弱。 |
| 1 | `noise` | 噪声或非 chirp 结构。 |

## 2. 目录与关键文件

| 路径 | 用途 | 维护说明 |
| --- | --- | --- |
| `gw_data.yaml` | 数据集路径、类别数和类别名称。 | 当前使用 Windows 相对路径；训练前确认 train、val 路径存在。 |
| `trian.py` | 当前训练入口。文件名为历史拼写，暂不改名以避免影响现有调用。 | 使用 chirp 专用模型配置与输出目录。 |
| `configs/yolo26m-chirp-attn-seg.yaml` | 当前 chirp 感知分割模型。 | 在原始 neck 后增加 P3/P4 的 C2PSA 注意力细化。 |
| `yolo26m-seg.pt` | 预训练初始化权重。 | 仅作为初始化来源，不应覆盖。 |
| `segment_new/` | 新训练实验的输出根目录。 | 由训练程序自动创建；不要把旧实验输出写入此目录的同名任务。 |
| `predict.py` | 批量推理与结果导出。 | 当前含硬编码路径，运行前必须检查。 |
| `analysis.py`、`line_find.py` | 单图时频分析与坐标轴定位。 | 依赖图像坐标轴检测结果，需处理未找到线条的情况。 |
| `img2640.py` | 图像预处理与缩放工具。 | 当前 `resize_fill` 会改变长宽比；训练、验证和推理必须使用一致策略。 |

## 3. 当前训练方案

运行命令：

```powershell
conda run -n yolo python trian.py
```

训练入口 `trian.py` 的关键约束如下：

- 架构配置为 `configs/yolo26m-chirp-attn-seg.yaml`，并由 `yolo26m-seg.pt` 初始化可匹配权重。
- 训练输出必须使用 `project=Path("segment_new")`、`name="chirp_c2psa"` 和 `exist_ok=False`。
- 因此权重保存到 `segment_new/chirp_c2psa*/weights/best.pt`；若同名实验已存在，Ultralytics 会创建递增目录，绝不覆盖旧模型。
- 当前图像尺寸为 `imgsz=640`，训练 300 个 epoch，Windows 下 `workers=0`。
- 优化器为 AdamW；`lr0=0.002`、`lrf=0.01`、余弦学习率、5 个 warm-up epoch、`weight_decay=0.0005`。
- `mask_ratio=2` 用于保留细弱 chirp 的更多掩膜细节；`cls=1.5`、`box=8.0` 用于加强分类与细长目标定位。

## 4. Chirp 定向增强和注意力设计

chirp 是具有明确时频扫频方向的细长曲线，增强不能破坏该物理结构：

- 保持关闭：旋转 `degrees=0`、上下翻转 `flipud=0`、左右翻转 `fliplr=0`、HSV 颜色扰动。
- 保留弱增强：`translate=0.08`、`scale=0.20`，以模拟合理的时间/频率位置与尺度变化。
- 控制组合增强：`mosaic=0.35`、`mixup=0.05`、`erasing=0.15`，并在最后 20 个 epoch 关闭 Mosaic。过强的组合或擦除会割裂微弱且连续的 chirp 轨迹。

模型中的 C2PSA 为带残差连接的位置敏感自注意力：

- P3 使用 1 个 C2PSA 块，优先保留细线和局部轨迹细节。
- P4 使用 2 个 C2PSA 块，在较低计算成本下学习曲线连续性与上下文。
- 检测/分割头使用注意力细化后的 P3、P4 与原始 P5 特征。
- 不要直接加深 P3 注意力。`imgsz=640` 时 P3 特征图约为 80×80，自注意力显存随空间位置数的平方增长。

## 5. 显存与训练稳定性

曾在分割损失计算期间出现 `CUDA out of memory`。原因是 640 分辨率的分割任务、深 P3 自注意力和 `batch=8` 同时造成了高显存峰值。

当前安全起点：

- `batch=2`
- `amp=True`（自动混合精度）
- P3 使用 1 个、P4 使用 2 个 C2PSA

Ultralytics 会使用梯度累积来补偿较小的物理 batch。若仍出现 OOM，优先将 `batch` 改为 `1`；只有 GPU 资源仍无法满足时再考虑降低 `imgsz`，因为 640 分辨率对细弱 chirp 的分割更有利。

## 6. 数据、标签和推理约束

- 训练图像位于 `train/images`，标签位于 `train/labels`；验证集由 `gw_data.yaml` 指向 `val/val_3.0`。
- 图像与同名标签必须一一对应，类别 ID 只能为 0 或 1。
- 训练标签通常是 5 列 YOLO 格式；推理导出的标签可能额外包含置信度列，不能直接回灌到训练集。
- `predict.py` 当前主要导出检测框。若业务需要分割轮廓，必须明确导出 masks 或多边形标签。
- 训练、验证和推理应使用相同的尺寸与预处理策略，否则时频形状比例不一致会影响结果。

## 7. 实验记录要求

每次正式实验必须记录：

1. 数据划分和数据版本；
2. 初始化权重、模型配置、GPU 型号/显存、实际 batch 和 epoch；
3. `mAP50-95`、chirp 召回率、误检率；
4. 训练耗时、推理延迟和最终 `best.pt` 路径。

在与基线模型使用相同数据划分和训练条件完成对比前，不应宣称新注意力机制带来了稳定性能提升。

## 8. GW5.0 事件级评估与固定训练集优化方向

### 当前可复现结果（2026-07-24）

- 最新完成权重为 `runs/segment/segment_new/chirp_c2psa-2/weights/best.pt`。
- `imgs/gw5.0` 含 429 张 H1、L1、V1 时频图；在 `conf=0.25`、`imgsz=640` 下共导出 128 个 chirp 预测。
- `事件数据.pdf` 有 161 个事件，其中 57 个事件的质量字段为 `--`，不纳入召回率分母。
- 对 104 个质量信息完整事件，按“任一探测器图像检出类别 0 chirp 即召回”的事件级口径，结果为 88/104，即 84.62%。完整审计见 `docs/gw5_recall_details.csv`，汇总见 `docs/gw5_recall_summary.json`。
- 使用 `evaluate_gw5_recall.py` 重建审计；脚本只读取 PDF 和预测标签，避免手工统计偏差。

### 训练集不变时的优化优先级

1. **先做阈值扫描，不重训。** 对同一组预测标签扫描 `conf=0.05` 至 `0.60`，按固定事件级口径同时记录召回率、每事件检出数和误报代理指标；选择满足业务误报约束的最高召回阈值。当前 0.25 仅是起始点。
2. **用固定验证集进行损失与超参数小范围消融。** 保持 331/83 图像、标签和随机种子不变；依次比较 `cls`、`box`、`mask_ratio`、`lr0`、`weight_decay`、`mosaic/mixup/erasing`。每次只改变一组变量，并报告 mAP、类别 0 召回和 GW5.0 事件级召回。
3. **以未召回事件为固定困难集。** 将 16 个未召回且质量完整的事件作为错误分析清单，检查其各探测器图像中的 SNR、轨迹长度、频率范围、噪声纹理和标签覆盖情况；训练数据不新增时，可通过采样权重或损失权重增加现有困难样本的训练贡献。
4. **调整采样而非扩充数据。** 在不增删训练样本的前提下，使用类别均衡采样、包含 chirp 的图像过采样、或基于现有标签面积/细长度的难例采样；必须固定总 epoch 或总优化步数并记录重复采样策略。
5. **保持物理一致的增强，重点扫强度。** 禁止旋转和翻转；在当前 `translate=0.08`、`scale=0.20` 附近做小范围扫描。优先降低可能截断细弱轨迹的 `erasing`、`mosaic`、`mixup`，而不是引入会改变扫频方向的增强。
6. **结构消融需控制计算量。** 对比无 C2PSA、仅 P4 C2PSA、当前 P3+P4 C2PSA；保持 `imgsz=640`、batch、优化器、训练轮数一致。P3 注意力块不可盲目加深，以免在 80x80 特征图上导致显存峰值和不稳定。
7. **采用重复训练判断稳定性。** 每个候选设置至少使用 3 个随机种子，在固定验证集和固定 GW5.0 审计上报告均值与标准差；单次最优结果不能作为结构改进结论。

### 比较与发布约束

- 每次实验必须记录权重路径、配置 diff、随机种子、训练耗时、最佳 epoch、验证指标和事件级审计 CSV。
- 基线与候选模型必须共享完全相同的训练/验证划分、GW5.0 图片、置信度阈值和质量缺失剔除规则。
- 除召回率外，还应记录每张图的 chirp 预测数、无质量事件中的检出数及人工复核样本，以防单纯降低阈值造成不可接受的误报。

## 9. 2026-07-26 迭代优化结论

### 固定验证集

- 原始 baseline 的总体掩膜 mAP50-95 为 0.42994，chirp 掩膜召回为
  0.80769，chirp 掩膜 mAP50-95 为 0.44584，推理为 27.29 ms/图。
- C2PSA 候选对应指标为 0.39123、0.74359、0.41077 和 46.44 ms/图。
- 当前 C2PSA 完整方案已判定为负向实验，不能替换 baseline；它只因错误互补而保留为
  后融合研究成员。

### GW5 事件级推理

在固定阈值 0.25 下：

- baseline@640：85/104，134 张探测器图像命中，14.19 秒。
- c2psa@640：88/104，128 张探测器图像命中，21.43 秒。
- baseline 的 512/640/768 多尺度决策融合：96/104，168 张命中，44.90 秒。
- baseline 与 C2PSA 的 640 后融合：99/104，169 张命中，35.62 秒。
- 全模型全尺度融合：100/104，192 张命中，112.23 秒。

经成本约束校准，全融合使用阈值 0.30 仍为 100/104，并将命中数降至 186。
具体原始结果见 `docs/experiments/`。

### 当前瓶颈

GW5 是正事件目录，不含纯负样本，因此“探测器图像命中率”只能表示人工复核工作量，
不能表示真实误报率。生产发布前必须增加独立负样本集，并报告 Precision、
false alarms/day 或等价误报约束。结构优化还必须做锁定训练变量的三随机种子消融。

## 10. 2026-07-26 阴性代理与级联续测

- 固定验证集有 69 张 chirp 阳性图、14 张 chirp 阴性图。
- 阈值 0.25 时，baseline 为 TP=67、FP=3、FN=2；双模型融合为
  TP=68、FP=5、FN=1。融合的额外召回伴随更高误报代理。
- 在 FPR 不超过 3/14 的暂时约束下，推荐工作点为 baseline@0.20：
  验证 Recall 98.55%，GW5 召回 90/104。
- 高召回研究模式使用 baseline→C2PSA 级联@0.25：GW5 保持 99/104，
  169 张图像命中，总耗时从完整融合的 36.42 秒降至 29.55 秒。
- 级联首轮因路径列表被当作整批输入而 OOM；逐图调用并复用 predictor 后稳定通过。
- 14 张阴性图不足以支持生产误报结论，仍需大规模、按时间隔离的纯负样本。

## 11. 2026-07-26 FP16 与 micro-batch 消融

- FP16+batch1 在验证集维持融合 TP=68、FP=5、FN=1、TN=9。
- FP16 级联在 GW5 保持 99/104，图像命中从 FP32 的 169 降至 168。
- GW5 级联耗时从 FP32 的 29.55 秒降至 22.40 秒，降低 24.20%。
- FP32+batch2 与 FP16+batch2 都发生置信度塌缩，只召回 1/69 张验证阳性图。
  根因是当前 Ultralytics 对路径列表内存批次的处理，不是 FP16。
- 高召回研究模式允许 `half=True`，但必须保持 `chunk_size=1`；任何更大路径
  micro-batch 都需重新验证后才能启用。

## 12. 2026-07-26 Attention Residual 非对称阈值校准

- 新增 `scripts/calibrate_attention_fusion.py`，只用固定验证集选择 baseline 与
  Attention Residual 的独立阈值，GW5 不参与选参。
- 在验证 FP 不超过 3/14 的约束下，3600 个组合中选择出 baseline=0.14、
  Attention Residual=0.36；验证结果为 TP=68、FP=3、FN=1、TN=11。
- 冻结策略后重跑 GW5 得到 100/104，命中 171/429 张探测器图像；Attention Residual
  调用 273 次，级联耗时 27.21 秒，比完整双模型 34.94 秒节省 22.11%。
- `scripts/benchmark_cascade.py` 已支持 `--secondary-threshold`，并验证非对称级联与
  完整非对称 OR 的二值结果一致。
- 剩余 4 个事件中，`GW240922_142106` 在 `imgs/gw5.0` 没有对应图像；另外 3 个事件
  的双模型最高分均低于 0.04。所有满足 FP<=3 的阈值组合最多仍召回 100/104，
  因而同一批分数上的阈值继续下降已经到达瓶颈。
- 下一步不得继续用 GW5 反复挑阈值。必须先补齐缺失探测器图像与时间隔离纯负样本，
  再执行冻结超参数的 baseline、仅 P4 Attention Residual、P3+P4 Attention Residual
  三随机种子消融；生产结论仍需 false alarms/day。

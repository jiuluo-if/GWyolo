# 批次 00：固定验证集基线复核

## 目标

在完全相同的 83 张验证图像、`imgsz=640`、batch 1 和 Ultralytics
8.4.66 环境下，复核原始 YOLO26m 分割基线与 C2PSA chirp 候选模型。

## 环境

- GPU：NVIDIA GeForce RTX 4060 Laptop GPU，8188 MiB
- PyTorch：2.12.0+cu130
- CUDA：13.0
- 数据：331 张训练图像、83 张验证图像

## 结果

| 指标 | baseline | c2psa | c2psa 相对变化 |
| --- | ---: | ---: | ---: |
| 总体掩膜 mAP50-95 | 0.42994 | 0.39123 | -9.00% |
| chirp 掩膜 Precision | 0.85958 | 0.79993 | -6.94% |
| chirp 掩膜 Recall | 0.80769 | 0.74359 | -7.94% |
| chirp 掩膜 mAP50-95 | 0.44584 | 0.41077 | -7.87% |
| 单图推理时间 | 27.29 ms | 46.44 ms | +70.14% |
| 已完成训练耗时 | 7915.54 s | 17754.40 s | +124.30% |

原始数据见 `validation_summary.csv` 和 `validation_summary.json`。

## 决策

C2PSA 候选在精度、chirp 召回和推理延迟上均未超过 baseline，不能替换
当前基础模型。它在 GW5 事件集的特定工作点可能提供互补检出，因此只保留为后融合
研究成员，不作为单模型发布候选。

## 局限

- 只有一个随机种子的现成权重，不能评估训练方差。
- 两个训练任务的优化器、batch、增强和掩膜下采样设置不同，因此本批可以否决
  “当前完整方案优于基线”，但不能单独归因 C2PSA 结构本身。
- 下一次结构消融必须锁定除模型结构外的全部训练变量，并至少使用 3 个种子。

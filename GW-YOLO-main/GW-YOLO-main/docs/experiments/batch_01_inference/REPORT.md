# GW5 优化批次对比报告

## 评估口径

- 事件级召回：质量字段完整的事件中，任一探测器图像检出 chirp。
- 探测器图像命中率：需要人工复核的工作量代理，不是真实误报率。
- 所有阈值共用同一次低阈值推理结果，避免重复推理造成口径漂移。

## 与现有方案对比

| 候选 | 相对 c2psa@640 的召回变化 | 图像命中变化 | 耗时倍数 |
| --- | ---: | ---: | ---: |
| baseline@multiscale | +8 事件（+7.69 个百分点） | +40 | 2.09× |
| ensemble@640 | +11 事件（+10.58 个百分点） | +41 | 1.66× |
| ensemble@multiscale | +12 事件（+11.54 个百分点） | +64 | 5.24× |

`ensemble@640` 在本批中是召回与计算成本最平衡的研究候选：99/104，只遗漏
`GW240601_231004`、`GW240916_184352`、`GW240922_142106`、
`GW241009_022835`、`GW241114_235258`。全融合再找回其中一个事件，但耗时增加到
112.23 秒。

## 技术结论

- 多尺度决策融合有效：baseline 从 85/104 提升到 96/104。
- 模型后融合有效：同为 640 输入时，两个模型的并集从单模型的 85/104 和
  88/104 提升到 99/104，说明错误具有互补性。
- 768 单尺度没有稳定超过 640，不能用单纯放大输入替代融合。
- C2PSA 的固定验证集质量更差，因此它只能作为补充成员；不能因事件目录召回更高
  就替换 baseline。

## 结论约束

GW5 目录只包含已知事件，缺少纯负样本。因此降低阈值或做并集融合带来的召回提升，
必须与固定验证集精度以及独立负样本集联合判断后，才能称为可发布优化。

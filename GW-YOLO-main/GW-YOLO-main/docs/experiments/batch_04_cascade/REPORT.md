# 批次 04：baseline→C2PSA 级联推理

## 技术

baseline 首先处理全部图像。若最高 chirp 置信度低于工作阈值 0.25，才调用 C2PSA。
当 baseline 已超过阈值时，第二模型不可能改变 OR 融合的二值结论，因此可以安全跳过。

## GW5 实测

| 指标 | 完整双模型融合 | 级联 |
| --- | ---: | ---: |
| 事件召回 | 99/104（95.19%） | 99/104（95.19%） |
| 探测器图像命中 | 169/429 | 169/429 |
| 总耗时 | 36.42 s | 29.55 s |
| 第二模型调用 | 429 | 295 |

级联减少 31.24% 的第二模型调用，并将总耗时降低 18.87%，同时保持与完整 OR 融合
完全相同的事件和图像二值决策。仍遗漏 5 个事件：

- `GW240601_231004`
- `GW240916_184352`
- `GW240922_142106`
- `GW241009_022835`
- `GW241114_235258`

## 验证集实测

- 完整融合：7.23 s。
- 级联：3.71 s。
- 第二模型调用：13/83（15.66%）。
- 节省时间：48.72%。
- 阈值 0.25 的二值结果仍与完整融合一致。

## 失败与修正记录

首轮实现把 83 个路径作为 Python 列表一次传入 Ultralytics。当前版本将其视作一个
内存批次，C2PSA 注意力尝试申请约 25.3 GiB 并触发 OOM。修正为逐图调用并复用
predictor 后，物理 batch 恒为 1，完整验证和 GW5 测试均通过。

## 决策

级联已确认是有效的计算优化，可用于后续高召回研究模式。但它没有改善融合本身的误报
权衡：验证阴性代理仍为 5/14 FP。因此生产默认仍使用 baseline；若业务确认高召回
模式，优先部署级联而不是无条件双模型推理。

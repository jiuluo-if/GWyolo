# 批次 09：跨尺度一致性救援

## 新技术

在冻结的 baseline@640 与 Attention Residual@640 两级级联后，增加 baseline 的
512/768 一致性判断。只有两尺度都超过各自阈值才判阳，避免由单一尺度伪影触发。

```text
baseline640 >= 0.14
OR attention640 >= 0.36
OR (baseline512 >= 0.15 AND baseline768 >= 0.07)
```

## 验证集校准

只在固定验证集穷举 60×60=3600 组阈值，约束 `FP<=3`。排序为最大 TP、最小 FP，
同指标时选择更高的组合阈值。GW5 不参与排序。

| 指标 | 两级策略 | 跨尺度一致性 |
| --- | ---: | ---: |
| TP/FP/FN/TN | 68/3/1/11 | **69/3/0/11** |
| Precision | 95.77% | 95.83% |
| Recall | 98.55% | **100%** |

唯一验证 FN 在 baseline@512/768 的分数为 0.15956/0.07180；一个单尺度高分阴性样本
在 512 为 0.55365、768 仅 0.02223，因此被一致性规则排除。

## 决策

接受为新的高召回研究策略。它在不增加现有验证 FP 代理的情况下找回全部验证阳性，
并在冻结 GW5 盲评中多召回 1 个事件。14 张阴性代理仍不足以支持生产结论。

# 批次 10：短路跨尺度一致性级联

## 目标

保持批次 09 的逻辑完全不变，但按条件执行：

1. baseline@640 先行；
2. 未过 0.14 才运行 Attention@640；
3. 前两级均未过阈值才运行 baseline@512；
4. 只有 512 分数达到 0.15 才运行 baseline@768。

第四步利用 AND 条件短路，不改变任何二值决策。

## 实测结果

| 验证 83 图 | TP/FP/FN/TN | 69/3/0/11 |

批次 08 的四成员全量推理实测总和约为 63.38 秒；短路执行降低约 47.07%。相对批次
07 的两级策略 28.84 秒，新增一致性救援增加约 4.71 秒并多召回 1 个事件。

## 决策

接受短路调度为批次 09 策略的唯一运行实现。禁止为方便而对全部图像无条件运行 768，
也继续禁止路径列表 `chunk_size>1`。

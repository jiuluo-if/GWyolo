# 批次 11：Attention Residual 三结构烟雾训练

## 目标

用 baseline、仅 P4 Attention Residual、P3+P4 Attention Residual 各 1 epoch、
seed 0 检查受控训练入口的权重迁移、显存和完整训练/验证链路。此批次不是收敛实验，
不得用 1 epoch 指标判断结构优劣。

## 结果

| 结构 | 头部迁移 | 耗时 | 峰值显存 | mask mAP50-95 | 单图推理 |
| --- | ---: | ---: | ---: | ---: | ---: |
| baseline | 362/376 | 55.51 s | 2.52 GiB | 0.10836 | 15.5 ms |
| P4 | 362/376 | 53.28 s | 2.50 GiB | 0.07416 | 16.3 ms |
| P3+P4 | 362/376 | 73.80 s | 5.44 GiB | 0.08312 | 25.0 ms |

三种拓扑都在 RTX 4060 Laptop 8 GiB、batch=2、AMP 下完成训练和验证。

## 发现并修复的结构问题

相对 `--project` 会被当前 Ultralytics 再次加上默认 `runs/segment`，使实验清单位于
预期目录而训练结果落到嵌套目录。训练入口现已在创建任务与清单前把 project 规范化
为绝对路径，并增加单元测试，恢复“清单、冲突检查、真实输出”三者一致。

首次 `conda run` 还因 GBK 无法回显训练日志而返回非零码；绕过 conda 回显、直接使用
同一 `yolo` 环境 Python 并启用 UTF-8 后三任务成功。该问题属于启动层编码，不是 GPU
训练失败。

## 决策

接受训练入口的可运行性与路径修复。正式结构结论仍必须完成 3 个结构 × 3 个种子 ×
300 epoch，并报告均值、标准差、GW5、负集 FP/FAR、延迟和显存。

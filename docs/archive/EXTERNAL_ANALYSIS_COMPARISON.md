## 总体结论

外部分析对本轮工作的**实验纪律**评价基本准确：非对称阈值没有用 GW5 选参，穷举已证明在“现有两模型分数 + 验证 `FP<=3`”这一限定下继续挖阈值没有收益，且受控三结构多种子训练入口确实消除了此前训练契约不一致的主要混杂因素。

但其对结果强度和下一步的几项推断过强。特别是，不能由 171/429 的“探测器图像命中数”推得随机基线、z 分数或“超出随机”的百分点；也不能把 `100/103` 称作整个研究路线的物理上限。当前证据只支持把**当前两权重、当前图像和当前验证 FP 代理约束下的阈值搜索**冻结，而不支持宣布阈值策略为永久最终结论，亦不支持放弃受控多种子消融。

## 对当前结果的准确定位

1. **单模型结论已足够明确，但不是结构因果结论。** 现成 Attention Residual 权重在同一固定验证集上弱于 baseline（chirp mask mAP50-95：0.41077 vs 0.44584；单图：46.44 ms vs 27.29 ms），所以不能替换 baseline。由于旧训练设置未完全锁定且各只有一个种子，这只能否定“当前完整候选可替换 baseline”，不能单独证明 C2PSA 结构必然无效。
2. **级联是有价值的研究候选，而不是生产策略。** 验证代理上非对称级联为 TP/FP/FN/TN=68/3/1/11，与 baseline@0.20 的 FP 代理相同；冻结后 GW5 为 100/104。14 个阴性样本使一个 FP 就改变 7.14 个百分点 FPR，因此不能外推 Precision、FAR 或 false alarms/day。
3. **100/104 不是完整性意义上的“极限”。** 它是当前双模型、当前阈值可行域和当前数据覆盖下的观察上限。其中一例缺图造成数据覆盖硬上限 103/104，另三例只是当前模型分数低；新输入或新模型仍可能改变其可检出性。

## 建议的行动顺序

1. **立即完成数据完整性审计。** 查找或确认 `GW240922_142106` 的 H1/L1/V1 源图、命名规则与目录清单；审计结果应写入事件 CSV，并明确它是“缺图”还是“源站无产品”。
2. **冻结当前分数上的阈值探索，但不要永久冻结参数。** 将 `baseline=0.14`、`attention=0.36`、验证约束和网格结果登记为“当前高召回研究工作点”；禁止利用 GW5 继续挑选它。新负集或新模型出现后，以独立校准集重选。
3. **先做负集可行性验证，而非直接断言整体迁移。** 明确连续数据的来源、时间隔离规则、Q-transform 参数、与训练 PNG 的分辨率/归一化差异，以及事件污染排除规则。先生成一个小型、版本化试验集，检查图像域和模型 FP；通过后再决定再训练或全面迁移。
4. **保留并执行受控多种子消融。** 若资源受限，可与负集准备并行、设为低优先级；正式报告至少给出三个种子的均值/标准差、验证 box/mask 指标、冻结阈值下的 GW5 召回、负集 FP/FAR、延迟和显存。它回答结构问题，负集工作回答可部署性问题，两者不能互相替代。

> 当前项目在防止 GW5 阈值泄漏、审计可复现性和后续受控结构比较设计上达到较高质量。非对称级联是现有两模型在固定验证 FP 代理约束下的最佳高召回研究工作点；其对同阈值融合有小幅事件召回和延迟优势，但受限于 14 张阴性代理与 GW5 缺少纯负观测时间，尚不能构成生产性能或统计显著性主张。当前应停止在同一批分数上继续调阈值，优先核对缺失图像并建立时间隔离负集；同时完成多种子受控消融，以确定 Attention Residual 的互补性是否可重复。

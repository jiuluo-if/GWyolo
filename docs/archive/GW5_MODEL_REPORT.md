# GW5.0 Chirp 模型报告

## 结论

使用最新训练完成的 `chirp_c2psa-2` 分割模型，在 `imgs/gw5.0` 的 429 张探测器时频图上进行预测。按“质量信息完整的事件中，H1、L1、V1 任一探测器检出 chirp 即记为召回”的规则，事件级召回率为 **84.62%（88/104）**。

## GW5.0 推理设置

- 输入：`imgs/gw5.0`，共 429 张 H1、L1、V1 时频图。
- 推理尺寸：`imgsz=640`；chirp 置信度阈值：0.25。
- 预测结果：`runs/filtered/predict_5.0/images` 与 `runs/filtered/predict_5.0/labels`。
- 类别 0（chirp）检出框总数：128。

## 事件级召回率

事件目录来自 `事件数据.pdf`（8 页、161 个事件），已进行页面视觉核查，并解析事件名、网络 SNR、质量 1、质量 2 字段。

统计步骤如下：

1. 质量 1 或质量 2 为 `--` 的事件不纳入分母；
2. 对其余事件，只要任一 H1、L1、V1 图像存在类别 0（chirp）预测，即计为召回；
3. 同一事件被多个探测器检出时只计一次。

| 项目 | 数值 |
| --- | ---: |
| PDF 目录事件数 | 161 |
| 剔除：无伴星质量事件数 | 57 |
| 纳入统计事件数 | 104 |
| 召回事件数 | 88 |
| 事件级召回率 | **84.62%（88/104）** |

未召回的 16 个纳入统计事件为：`GW240507_041632`、`GW240512_024139`、`GW240527_230910`、`GW240601_231004`、`GW240618_071627`、`GW240908_125134`、`GW240915_105151`、`GW240916_184352`、`GW240922_142106`、`GW241009_022835`、`GW241109_033317`、`GW241114_235258`、`GW241116_151753`、`GW241130_110422`、`GW241229_155844`、`GW250114_082203`。

## 结果解读

84.62% 是固定阈值 0.25 下的事件级召回率，不等同于 mAP，也不代表误报率。若要证明结构改进有效，应在相同图像、阈值与事件口径下，对基线模型重复本审计。

# GW-YOLO 完整优化报告

## 结论

本轮建立了可复现的“基线验证—低阈值一次推理—多尺度/模型后融合—阈值扫描—
成本约束选择”实验链路。当前 C2PSA 单模型并非有效替代：固定验证集精度更低、
推理更慢。有效的新技术集中在推理决策层：

1. baseline 多尺度融合将 GW5 事件召回从 85/104 提升到 96/104；
2. baseline 与 C2PSA 的 640 后融合达到 99/104；
3. 全模型全尺度融合在阈值 0.30 达到 100/104，探测器图像命中率 43.36%；
4. 由于没有纯负样本，上述融合仅批准为研究候选，生产默认仍保留 baseline。

## 批次 00：验证集复核

| 指标 | baseline | c2psa |
| --- | ---: | ---: |
| 总体掩膜 mAP50-95 | 0.42994 | 0.39123 |
| chirp 掩膜 Precision | 0.85958 | 0.79993 |
| chirp 掩膜 Recall | 0.80769 | 0.74359 |
| chirp 掩膜 mAP50-95 | 0.44584 | 0.41077 |
| 推理 | 27.29 ms/图 | 46.44 ms/图 |
| 已完成训练耗时 | 7915.54 s | 17754.40 s |

C2PSA 的 chirp 掩膜 mAP50-95 下降 7.87%，推理延迟增加 70.14%。该方案被否决为
默认模型。详细数据见 `experiments/batch_00_validation/`。

## 批次 01：多尺度与模型后融合

固定阈值 0.25：

| 候选 | 事件召回 | 图像命中率 | 总耗时 |
| --- | ---: | ---: | ---: |
| baseline@640 | 85/104（81.73%） | 31.24% | 14.19 s |
| c2psa@640 | 88/104（84.62%） | 29.84% | 21.43 s |
| baseline@multiscale | 96/104（92.31%） | 39.16% | 44.90 s |
| ensemble@640 | 99/104（95.19%） | 39.39% | 35.62 s |
| ensemble@multiscale | 100/104（96.15%） | 44.76% | 112.23 s |

模型后融合证明两个权重的事件级错误具有互补性。`ensemble@640` 是本轮最平衡的
高召回研究候选；全融合只多召回一个事件，却增加约 3.15 倍总耗时。

## 批次 02：Pareto 成本校准

| 研究档位 | 约束 | 选择 | 事件召回 |
| --- | --- | --- | ---: |
| efficient | 命中率 ≤30%，耗时 ≤25 s | c2psa@640，阈值 0.25 | 88/104 |
| balanced | 命中率 ≤40%，耗时 ≤50 s | ensemble@640，阈值 0.25 | 99/104 |
| max_recall | 命中率 ≤45%，耗时 ≤120 s | 全融合，阈值 0.30 | 100/104 |

全融合从 0.25 提高到 0.30 后召回不变，命中图像从 192 降到 186，因此 0.30 是更优
工作点。档位预算是研究示例，不是业务验收值。

## 批次 03：阴性代理校准

固定验证集包含 69 张 chirp 阳性图和 14 张 chirp 阴性图。阈值 0.25 下，baseline
为 TP=67、FP=3、FN=2；完整双模型融合为 TP=68、FP=5、FN=1。融合多找回一张
阳性图，但多产生两张阴性误报。

在不超过 3/14 阴性误报的暂时约束下，baseline@0.20 是更优工作点：
验证 Recall 98.55%，GW5 事件召回 90/104，且计算成本低于 C2PSA 与融合。

## 批次 04：级联推理

baseline 先运行，只对 baseline 低于 0.25 的图像调用 C2PSA。GW5 实测保持完整
OR 融合的 99/104 与 169 张命中不变，将第二模型调用从 429 次降至 295 次，
总耗时从 36.42 秒降至 29.55 秒，节省 18.87%。验证集耗时从 7.23 秒降至
3.71 秒，节省 48.72%。

首轮列表批处理触发约 25.3 GiB 的注意力显存申请；改为逐图复用 predictor 后通过。
级联被确认是计算优化，但不是误报优化。

## 批次 05：FP16 与 micro-batch 消融

FP16+batch1 在 GW5 保持级联事件召回 99/104，图像命中从 169 降到 168，
总耗时从 29.55 秒降到 22.40 秒，进一步节省 24.20%，因此被接受为高召回
研究模式的推理选项。

FP32+batch2 和 FP16+batch2 都只召回 1/69 张验证阳性图，证明路径列表
micro-batch 会造成置信度系统性塌缩。该选项被拒绝，并在命令中强制建议
`chunk_size=1`。

## 发布决策与瓶颈

当前可提交研究代码与报告，但不能将融合策略标记为生产误报优化，原因有三：

1. 只有 14 张验证阴性代理，无法估计实际观测中的 false alarms/day；
2. C2PSA 与 baseline 的训练超参数不完全相同，无法把差异严格归因于结构；
3. 每个方案只有一个随机种子，没有均值、标准差与显著性结论。

当前生产研究建议更新为 baseline@0.20；高召回研究模式使用阈值 0.25、
FP16、batch1 的 baseline→C2PSA 级联。

下一阶段的最小充分实验是：建立按时间隔离的负样本集；冻结数据、优化器和增强；
训练 baseline、仅 P4 C2PSA、P3+P4 C2PSA 各 3 个种子；联合报告验证集 mAP、
GW5 事件召回、负集 false alarms/day、延迟和显存。完成前，生产默认模型仍为
`runs/segment/train/weights/best.pt`。

# 批次 05：FP16 与路径 micro-batch 消融

## 目标

测试半精度推理和 micro-batch=2 能否继续降低级联耗时，并确认数值结果不改变既有
事件级结论。

## 验证集消融

| 设置 | 融合 TP/FP/FN/TN | 级联耗时 | 结论 |
| --- | --- | ---: | --- |
| FP32，batch1 | 68/5/1/9 | 3.71 s | 基准 |
| FP32，batch2 | 1/0/68/14 | 7.16 s | 置信度塌缩，拒绝 |
| FP16，batch2 | 1/0/68/14 | 7.44 s | 置信度塌缩，拒绝 |
| FP16，batch1 | 68/5/1/9 | 4.39 s | 决策正确 |

FP32 与 FP16 在 batch2 下同时失败，说明根因不是半精度，而是当前 Ultralytics
路径列表被作为内存批次时的处理语义。batch2 的 baseline 平均最高置信度从
0.7300 降至约 0.00875，只剩 1/69 张阳性图超过阈值 0.25。

FP16+batch1 在验证集维持完整融合 TP/FP/FN/TN 不变；完整融合耗时降低 3.96%，
但小验证集上的级联总耗时增加 18.45%，因此不能仅凭该小集判断加速。

## GW5 全量结果

| 指标 | FP32 级联 | FP16 级联 |
| --- | ---: | ---: |
| 事件召回 | 99/104 | 99/104 |
| 探测器图像命中 | 169/429 | 168/429 |
| 第二模型调用 | 295 | 295 |
| 总耗时 | 29.55 s | 22.40 s |

FP16 将 GW5 级联耗时进一步降低 24.20%；完整双模型耗时也从 36.42 秒降至
27.23 秒，降低 25.25%。FP16 与 FP32 只有一张图的阈值二值决策不同：
`GW240923_204006-v1-H1-qscan`，但事件级召回不变。

## 决策

- 接受：`half=True`、`chunk_size=1`，用于高召回研究级联。
- 拒绝：对路径列表使用任何未经单独验证的 `chunk_size>1`。
- 生产默认仍为 baseline@0.20；FP16 级联仍受 14 张阴性代理过小的限制。

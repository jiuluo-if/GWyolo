# 批次 06：Attention Residual 非对称阈值级联

## 目标

在保留 Attention Residual（P3/P4 C2PSA）模型的前提下，为 baseline 和
Attention Residual 分别校准置信度阈值。此前两个模型共用 `0.25` 阈值，完整 OR
融合在验证集增加了误报代理。本批次测试非对称双阈值是否能保留注意力模型的互补召回，
同时不超过 baseline 的验证误报上限。

## 防止 GW5 选参泄漏

- 阈值只用固定验证集的 69 张 chirp 阳性图和 14 张 chirp 阴性图选择。
- 约束为 `FP <= 3`，等于此前 baseline@0.20 的误报代理上限。
- 搜索范围为 baseline/Attention Residual 各 `0.01` 至 `0.60`、步长 `0.01`，
  共 3600 个组合。
- 排序规则为：最大化验证 TP、最小化 FP，再选择仍满足约束的最低阈值。
- GW5 不参与阈值排序，只在策略冻结后执行事件级盲评。

最终选择：

| 模型 | 阈值 |
| --- | ---: |
| baseline | 0.14 |
| Attention Residual | 0.36 |

级联首先运行 baseline；只有 baseline 置信度低于 0.14 时才调用 Attention Residual。
最终判定为 `baseline >= 0.14 OR attention >= 0.36`。

## 验证集结果

| 策略 | TP | FP | FN | TN | Precision | Recall | FPR |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| baseline@0.20 | 68 | 3 | 1 | 11 | 95.77% | 98.55% | 21.43% |
| 非对称级联 0.14/0.36 | 68 | 3 | 1 | 11 | 95.77% | 98.55% | 21.43% |

非对称级联没有增加当前验证阴性代理上的 FP。83 张验证图中仅 12 张需要调用
Attention Residual；实测级联耗时 3.75 秒，完整双模型推理为 7.23 秒，节省 48.17%。

## GW5 盲评

| 指标 | 结果 |
| --- | ---: |
| 纳入事件 | 104 |
| 召回事件 | **100/104（96.15%）** |
| 命中探测器图像 | 171/429（39.86%） |
| Attention Residual 调用 | 273/429（63.64%） |
| 级联耗时 | 27.21 秒 |
| 完整双模型耗时 | 34.94 秒 |
| 节省耗时 | 22.11% |

相对生产研究起点 baseline@0.20 的 90/104，本策略多召回 10 个事件，同时在现有
14 张验证阴性代理上保持相同的 3 个 FP。相对此前同阈值 0.25 的级联，本策略从
99/104 提升到 100/104，并把验证 FP 从 5 降到 3；代价是第二模型调用数和总耗时增加。

## 剩余事件与瓶颈

未召回事件：

| 事件 | baseline 最高分 | Attention Residual 最高分 | 说明 |
| --- | ---: | ---: | --- |
| `GW240601_231004` | 0 | 0.02939 | 两模型均远低于可行阈值 |
| `GW240922_142106` | — | — | `imgs/gw5.0` 中没有对应探测器图像 |
| `GW241009_022835` | 0.03192 | 0.03827 | 两模型均远低于可行阈值 |
| `GW241114_235258` | 0.01400 | 0.02221 | 两模型均远低于可行阈值 |

在 3600 个阈值组合中，1175 个满足 `FP <= 3`；其中验证 TP 的最高值仍为 68。
对所有可行组合进行只读瓶颈审计，GW5 最大召回仍为 100/104，共 9 个组合达到该上限。
因此仅继续降低两个现有模型的阈值无法越过当前瓶颈。

## 决策

- 接受非对称阈值级联为新的高召回研究策略。
- 不把 3/14 的阴性代理解释为生产误报率；默认生产发布仍需独立时间隔离负样本。
- 不继续在同一批分数上做阈值挖掘。下一轮模型层研究必须补齐缺失图像、冻结训练变量，
  并执行 baseline、仅 P4 Attention Residual、P3+P4 Attention Residual 的三种子消融。

原始结果见 `calibration_grid.csv`、`selected_policy.json`、
`validation_runtime/` 和 `gw5_runtime/`。
